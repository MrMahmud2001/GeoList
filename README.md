# Веб‑ориентированная геоинформационная система (ГИС) для сбора, систематизации и мониторинга данных о дорожной инфраструктуре


## Описание
Система разработана с использованием трехзвенной клиент-серверной архитектуры. Решение позволяет визуализировать пространственные данные из внешних источников (*KML-файлы*), структурировать их в реляционной базе MySQL и обеспечивать оперативный контроль за состоянием дорожных объектов через интерактивные заявки.

## Ключевые архитектурные решения
*   Клиентская часть: SPA-приложение без тяжелых фреймворков *(HTML5, CSS3, JS + Leaflet.js)*. Включает подсистемы фильтрации, отображения карты и управления заявками.
*   Серверная часть: Node.js + Express. Реализует REST API для взаимодействия с клиентом, модуль разбора KML‑файлов и логику маршрутизации запросов.
